# GaonWala Admin

Admin panel for **GaonWala** — a multi-grocery app for rural areas.  
This Flutter project provides an intuitive dashboard to manage categories, products, orders, coupons, and users efficiently.

---

## Features

- Dashboard with product and order summaries
- Manage categories, sub-categories, and products
- Coupon and discount management
- Order tracking and notifications
- User management
- Responsive Flutter web and mobile admin panel
